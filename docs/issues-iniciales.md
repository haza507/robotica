# Issues iniciales (para abrir en GitHub)

El enunciado pide **al menos un Issue abierto** que invite a contribuir. Ábranlos en la pestaña **Issues** del repositorio (botón *New issue*), copiando el título y el cuerpo. Etiquetas sugeridas: `good first issue`, `documentación`, `verificación`.

---

## Issue 1 · Verificar los puntos «no verificados» del proyecto original

**Etiquetas:** `verificación`

```markdown
## ¿Qué necesitamos?

En la [Ficha de OpenQuadruped](recursos/ficha-openquadruped.md) hay puntos marcados como **no verificados**:

- Contenido actual de la lista de materiales (BOM).
- Existencia de una guía completa de ensamblaje.
- Existencia de `CONTRIBUTING.md` y normas oficiales para contribuir.

## Cómo participar

1. Revisa el README, la Wiki y las carpetas del repositorio original.
2. Comenta aquí qué encontraste y dónde (con enlace).
3. Si puedes, actualiza la ficha con un Pull Request.
```

## Issue 2 · Leer la Ficha con mirada de principiante

**Etiquetas:** `good first issue`, `documentación`

```markdown
## ¿Qué necesitamos?

Alguien que **no haya participado** en este proyecto y lea la [Ficha de OpenQuadruped](recursos/ficha-openquadruped.md) y el [Glosario](recursos/glosario-y-faq-principiantes.md).

## Cómo participar

Comenta en este Issue:
- ¿Entendiste qué es OpenQuadruped y qué es una «pata de tres articulaciones»?
- ¿Qué término o paso te confundió?
- ¿Qué agregarías?

No necesitas experiencia en robótica.
```

## Issue 3 · Ampliar el glosario con términos que falten

**Etiquetas:** `good first issue`, `documentación`

```markdown
## ¿Qué necesitamos?

El [Glosario](recursos/glosario-y-faq-principiantes.md) es corto. Si te topaste con un término técnico que no está, cuéntanos.

## Cómo participar

- Escribe el término y, si lo sabes, una definición sencilla con su fuente, o
- Agrégalo tú con un Pull Request pequeño (ver CONTRIBUTING.md).

## Criterio de calidad
Cada definición debe poder entenderse sin saber robótica.
```
