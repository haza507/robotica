## Cómo se incorpora la retroalimentación

1. El comentario llega por Issue, Pull Request o durante una sesión.
2. Quien documenta lo anota en esta tabla en un plazo de 3 días.
3. Se decide en el Issue si se atiende, se pospone o no se atiende, y se explica por qué.
4. Cuando se hace el cambio, se enlaza al *commit* o al archivo modificado.
